# Graph Night

Dark-mode design system — "a graphing calculator at night."

- `DESIGN_SYSTEM.md` — full documentation: tokens, typography, components, recipes
- `css/graph-night.css` — drop-in stylesheet (no build step)
- `starter/starter.html` — boilerplate demonstrating every component
- `generator/` — Python page generator for stamping out many pages

Quick start: copy `starter/starter.html`, adjust the theme knobs in its inline
style block, and write content using the components shown.
